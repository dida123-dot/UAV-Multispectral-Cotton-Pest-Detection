## 文档约定

- 全部使用 Markdown，图片放在 `docs/images/`；
- 表格用于参数、指标、对比，避免大段文字罗列；
- 涉及指标必须写明数据集划分、模型权重与随机种子；
- 引用文献使用 `[n]` 编号，与 [references.md](references.md) 保持一致。
