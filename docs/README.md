- [ ] `dataset.md` — 数据来源、标注规范、严重度分级判定细则
- [ ] `references.md` — 参考文献与相关工作综述（从 research-plan 拆分并扩充）
- [ ] `experiment-log.md` — 实验记录台账（配置、指标、结论）

## 文档约定

- 全部使用 Markdown，图片放在 `docs/images/`；
- 表格用于参数、指标、对比，避免大段文字罗列；
- 涉及指标必须写明数据集划分、模型权重与随机种子。
