# models/ YOLOv11-RGBT 双流融合网络

在 Ultralytics YOLOv11 基础上扩展 RGB 与多光谱两个输入分支，实现跨模态特征融合。

## 网络设计

```text
        RGB 输入 (3×H×W)                多光谱特征 (8×H×W)
              │                                 │
        ┌─────▼─────┐                    ┌──────▼──────┐
        │  RGB 分支 │                    │  MSS 分支   │
        │ C2f×n+SPPF│                    │ 轻量 Stem   │
        └─────┬─────┘                    └──────┬──────┘
              │        ┌─ CBAM 通道/空间注意力 ─┐│
              └───────►│  P3 中期融合（Concat）  │◄┘
                       └───────────┬───────────┘
                             ┌─────▼─────┐
                             │  Neck + Head │  ← 增加 P2 小目标检测头
                             └───────────┘
```

| 设计点 | 说明 | 对应研究内容 |
|--------|------|--------------|
| 双流骨干 | RGB 分支复用 YOLOv11n/s 权重，多光谱分支为轻量 Stem，避免参数量爆炸 | 跨模态特征对齐 |
| CBAM 注意力 | 通道注意力 + 空间注意力，抑制背景与光照干扰 | 创新点 1 |
| P3 中期融合 | 在 P3 层做 Concat 融合，兼顾语义与分辨率 | 融合策略对比（早期/中期/晚期） |
| P2 小目标头 | 4× 下采样特征层，提升小目标召回 | 创新点 2 |
| 动态卷积 | 替换部分 Conv，按输入自适应加权 | 轻量化 |
